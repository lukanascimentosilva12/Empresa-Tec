# 💻 Compy — Soluções Digitais

Landing page institucional desenvolvida para uma empresa fictícia de tecnologia chamada Compy.

O projeto apresenta uma interface moderna para divulgação de serviços digitais, com seções voltadas para apresentação da empresa, serviços oferecidos, diferenciais, processo de trabalho e contato.

## 🚀 Funcionalidades

- Menu de navegação
- Seção de apresentação da empresa
- Apresentação dos serviços
- Seção de diferenciais
- Processo de trabalho dividido em etapas
- Seção de chamada para ação
- Rodapé com informações da empresa
- Efeitos de interação nos elementos
- Layout organizado em diferentes seções

## 🛠️ Tecnologias

- HTML5
- CSS3
- Google Fonts

## 📚 Conceitos praticados

- Estruturação semântica com HTML
- Organização de páginas em seções
- Flexbox
- CSS Grid/Layouts
- Gradientes
- Pseudo-classes `:hover`
- Posicionamento de elementos
- Tipografia e estilização
- Responsividade
- Organização de componentes visuais

## 🎨 Design

O projeto utiliza uma identidade visual baseada principalmente nas cores:

- Rosa
- Preto
- Branco
- Gradientes

A interface utiliza elementos como cards, botões, efeitos de hover, navegação fixa e diferentes seções para criar uma apresentação visual de uma empresa de tecnologia. :contentReference[oaicite:5]{index=5}
